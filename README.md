# noflyzone
 
**Overview**

This is a simple Fabric mod for Minecraft 1.21.1 which forces the player's flight to become disabled when they join a server, unless they have the bypass permission node "noflyzone.bypass", meaning Admins can fly uninterrupted.

**Features**

_Flight Restriction_
- Automatically disables player flight when joining a server, helping prevent unauthorised flight while keeping the experience straightforward.

- Disables flight when joining a server
- Admins and authorised players can bypass the restriction
- Supports the noflyzone.bypass permission node
- Lightweight and simple to configure
